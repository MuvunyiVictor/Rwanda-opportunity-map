📐 Methodology & Data Transparency

▼
🏠 Housing Gap Calculation
National Target: 5.5M homes by 2050 (Vision 2050)
Annual Need: 150,000 units per year
District Target (Priority Order):
  1. DDS numeric target (e.g., "200,000 units") → High Confidence
  2. DDS land allocation (ha × 50 units/ha) → Medium Confidence
  3. Population-based estimate (Pop ÷ 4.5 × 1.5) → Low Confidence
Current Housing: Population ÷ 4.5 (avg household size)
Formula: Gap = Target - Current
📌 Source: Vision 2050, NST2, DDS documents, NISR population data
⚠️ Districts with "TBD" targets use fallback estimates
💼 Jobs Gap Calculation
National Target: 1.25M new jobs by 2029 (NST2)
District Target (Priority Order):
  1. DDS numeric target → High Confidence
  2. Gap analysis worker needs → Medium Confidence
  3. Score-based estimate (20K + (Score/100 × 30K)) → Low Confidence
Current Jobs: 20,000 + (Composite Score / 100) × 30,000
Formula: Gap = Target - Current
📌 Source: NST2, DDS documents, composite scoring engine
💰 Investment Gap Calculation
National Target: $4.6B private investment by 2029 (NST2)
District Target (Priority Order):
  1. Gap analysis required investment → High Confidence
  2. DDS numeric target → Medium Confidence
  3. Score-based estimate ((Score/100) × $300M) → Low Confidence
Current Investment: From gap analysis or estimate
Formula: Gap = Target - Current
📌 Source: NST2, DDS gap analysis, RDB data
🏭 Industry Gap Calculation
National Target: Aggregated from DDS targets
District Target (Priority Order):
  1. DDS industrial zone targets → High Confidence
  2. Score-based estimate (1 + (Score/20)) → Low Confidence
Current Zones: Based on DDS progress or estimate
Formula: Gap = Target - Current
📌 Source: DDS documents, MINICOM data
🌾 Agriculture Gap Calculation
National Target: 80% target intensity
District Target: 80% (national standard)
Current Intensity: From agriculture_data.json (NISR data)
Formula: Gap = 80% - Current Intensity
📌 Source: NISR Seasonal Survey, agriculture_data.json
⚠️ Fallback Logic & Confidence Levels
High Confidence → Official DDS document with numeric targets
Medium Confidence → DDS gap analysis or land allocation
Low Confidence → Fallback estimates based on population/score
⚠️ 0% Gap Warning: When a district shows 0% gap but:
  • DDS target is "TBD" → Data incomplete
  • Using fallback estimate → Needs verification
  • Target is unrealistic compared to national targets → Flagged for review
💡 Recommendation: Add DDS documents for all districts to improve accuracy
📌 Data Sources Summary
● Vision 2050 → National housing target

● NISR Data → Population & agriculture

● Composite Score → Fallback estimates

📊 Scoring Methodology

▼
How Scores Are Calculated
Composite Score = (Land + Labor + Capital + Entrepreneurship) / 4
Each factor is normalized using min-max normalization: (Value − Min) / (Max − Min) × 100
This means each district's score is relative to the best and worst-performing districts. A score of 100 means the district is the best in that factor.
